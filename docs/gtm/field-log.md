# Field log

Append only. Every outreach batch, call, demo, post and pilot event gets a line.
This is the mechanism that turns the knowledge base from a library into
experience: judgments (J) in the knowledge files are graded here, and patterns
get confirmed or killed by what actually happened.

Format, one entry per event:

```
## YYYY-MM-DD, what it was
**Stood on:** which knowledge file or judgment this acted on
**Did:** what was actually sent, said or shown
**Result:** what happened, in their words where possible
**Verdict on the judgment:** confirmed, weakened, or killed
```
